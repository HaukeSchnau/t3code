# Open task artifacts beside a conversation

In the web and desktop apps, click a document link on `files.schnau.dev` to open it
in a tab beside the conversation. Published HTML pages and apps, PDFs, text,
Markdown, and JSON documents use the browser's document viewer. Markdown and
JSON appear as text, not a formatted report. Images, audio, and video retain their
existing media previews. Downloads and links to other hosts keep their usual action.

Opening the same URL again selects its tab. Use Reload after the agent updates the
file. Close the tab with its X; clicking the original link opens it again. Tabs are
kept separately for each conversation on your device. On smaller screens the panel
opens over the conversation and can be dismissed to return to chat.

Choose Open externally in the preview toolbar, or use Cmd/Ctrl-click on the original
link, to open the document in a separate browser tab or your system browser. The
link's context menu also offers both actions.

Your device must be able to reach `files.schnau.dev`. Some documents, directory
listings, or browser PDF viewers may prevent embedding; use Open externally if a
preview is blank or unavailable. The native mobile app retains its existing link
opening behavior.
