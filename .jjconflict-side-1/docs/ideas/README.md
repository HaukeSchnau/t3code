# Ideas

This directory collects product and architecture ideas that are worth preserving, but are not
implemented yet.

Ideas here should stay lightweight: capture the user problem, the desired experience, likely
implementation direction, and open questions. Move an idea into `patches/` only after it becomes a
fork-specific implementation that needs maintenance notes.
