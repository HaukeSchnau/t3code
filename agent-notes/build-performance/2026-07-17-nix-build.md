# Nix build performance, 2026-07-17

## Goal

Make srv-2 builds and deployments incremental, platform-specific, measurable, and substantially faster while
preserving the existing runtime and test behavior.

## Implemented workstreams

- Split web, server, production dependencies, and final assembly into independent Nix derivations.
- Filter pnpm dependency fetch/install to each derivation's workspace closure.
- Replace the hand-built production workspace with `pnpm deploy --prod`.
- Limit dependency artifacts to the current architecture and prune native prebuild directories.
- Pin pnpm 11.10, use fetcher v4, and trust the frozen lockfile.
- Disable production source maps while preserving development defaults.
- Separate Vitest configuration from production Vite configuration.

## Measurements

- Previous deployed output: 741 MiB total, including 681 MiB of dependencies and 36 MiB of web source maps.
- Previous dependency install: 1,785 packages and about 100 seconds of configure time.
- Optimized clean web derivation on srv-2: 583 packages, 30 seconds configure, 78 seconds Vite build,
  127 seconds end-to-end.
- Optimized aggregate build on srv-2: 196 seconds end-to-end with the three component derivations running
  independently (runtime 192 packages, server 364, web 583).
- Warm no-op Nix build: 3.792 seconds.
- Final closure: 1,038,914,320 bytes, down from 1,414,385,128 bytes (375,470,808 bytes / 26.55%).
- Direct outputs: 4.2 MiB final wrapper/server payload, 17 MiB web, and 382 MiB runtime dependencies.
- Removing `node-pty` build metadata reduced the runtime closure from 771 MiB to 615.9 MiB while retaining
  `build/Release/pty.node`; the final package still starts and reports `t3 v0.0.28`.
- Deployment time: pending final cutover.

## Verification status

- Optimized web and server outputs contain no production source maps, test files, or Vitest configuration.
- Server and runtime dependency derivations build independently; runtime imports for `node-pty`, FFF, and the
  Claude Agent SDK pass, and only the current Linux ARM64 FFF binary is present.
- `vp check`, `vp run typecheck`, focused web/server tests, `nix flake check --no-build --all-systems`, and the
  packaged `t3 --help` smoke test pass.
- The deterministic deploy-lock drift check passes with pinned pnpm 11.10, and the script restores the normal
  lock/workspace files. The final metadata-only incremental build rebuilt runtime/final while web and server
  remained cached, confirming component cache boundaries. Final independent review and srv-2 deployment follow.
